## M5-02 — Pilot (4 weekly runs) and success report
**Depends:** M5-01 · **Duration:** 4 weeks (about 2 h/week of developer time)

Weekly checklist (repeat 4 times):
1. The run completes unattended from cron in < 30 min.
   → verify: the run row shows timings; the heartbeat is OK.
2. The report holds 10 stories with all fields, and no unverified date is shown as verified.
   → verify: spot-check 5 stories.
3. The editor approves ≥ 1 of the top 3 (gate 1), then the drafts are evaluated.
   → verify: `topic.decided` events.
4. Drafts reach PASS within 2 loops (target ≥ 70 %). The editor rates them "publishable with light edits" (< 20 min).
   → verify: `quality_reports` + the editor's rating, recorded here.
5. 100 % of factual claims are sourced; no invented statistics or volumes.
   → verify: deterministic check results + the editor's spot check.
6. Cost per published article < $5.
   → verify: cost view.
7. Live E2E is nightly green, and no gate overrides were merged.
   → verify: the Actions history.

After week 4:
- [ ] Write the success report against each PRD §3 criterion (pass/fail + evidence) in `docs/plans/pilot-report.md`.
- [ ] Decide the next phase (image generation, CMS plugin, second workspace, or analytics loop) and record it as an ADR.
- [ ] Review the tech radar; update the risks.

**Done when:** the pilot report is written and the next-phase ADR is accepted.

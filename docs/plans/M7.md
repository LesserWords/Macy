# M7 — Macy Pocket (Path A & Path B), Capability Plugins, Zero-Key Adapters & Guided Setup

**Goal:** Make Macy trivial to install, configure, and modularize across **two complementary paths**:
- **Path B (Zero-Docker Stateless CLI/MCP Package — `M7-01`):** Installable via `uvx --from macy[core] macy ...` with composable extras and `--stateless` execution decoupling `audit`, bounded `--crawl`, deterministic draft compliance (`import-draft`), JSON-LD schema generation, and `stdio` MCP tools (`macy_audit_url`, `macy_crawl_site`, `macy_evaluate_draft`, `macy_import_draft`) from `engine/db.py` so they run with zero Docker and zero PostgreSQL ([ADR-029](../adr/ADR-029-capability-plugins-and-switchboard.md)).
- **Path A (Zero-Config Pocket Container Stack + Guided Setup — `M7-02`–`M7-04`):** A low-footprint `compose.pocket.yaml` stack with auto-bootstrapped secrets (`/data/.macy_secrets.json`), Python startup SQL migrations, an advisory-locked embedded worker, PBKDF2-HMAC-SHA256 local admin auth (`AUTH_MODE=local|oidc|auto`), zero-key/local adapters (`ollama`/`openai_compat`, `gnews_rss`, `autocomplete`), workspace capability switchboard (`core-compliance`, `seo-audit`, `editorial-pipeline`, `route-monitors`), and a bilingual 3-step First-Boot Setup Wizard with website URL + sitemap auto-seeding ([ADR-030](../adr/ADR-030-pocket-single-container-and-local-auth.md), [ADR-031](../adr/ADR-031-zero-key-adapters-and-guided-onboarding.md)).

**Exit gate:** `M7-01`–`M7-04` satisfy every **Delivery KR (`D1`–`D4`)** in their OpenSpec proposals and pass all `scripts/check.sh` gates (`100%` diff-cover, `>= 90%` branch coverage, `complexipy <= 15`, `jscpd = 0%`, `lint-imports`, `squawk`, `check_translations.py`, `openspec validate --all --strict --no-interactive`), with **Path B** verified statelessly (`DATABASE_URL` unset) across CLI + MCP and **Path A** verified end-to-end via offline E2E journey `J-POCKET`.

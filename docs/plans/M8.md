**Goal:** Decouple all maintainer-specific business context (`founder/` strategy docs, proprietary brand fixtures `seed_<brand>.yaml`, private vertical pack defaults, private outbound HTTP User-Agent URL, `prompts/score.md` vertical wording, and personal/company email identities) from the raw open-source engine using a **hybrid architecture**: a 3-layer cascading folder search path (`MACY_CONTEXT_DIR` → Pocket `/data/context` → built-in OSS) **plus** PostgreSQL `workspaces.config.industry_pack_snapshot` fallback and Admin UI `.yaml` import/export. Ship two bilingual generic starter packs (`general` and `b2b-saas`) + `seed_example.yaml` under Apache-2.0, retain and sanitize `openspec/changes/archive/**`, enforce an automated CI hygiene gate (`scripts/check_oss_hygiene.py`), and publish the clean orphan OSS release to `https://github.com/LesserWords/Macy.git` (maintaining the application name **`macy`**) while keeping the current repository as the private full-history & context store until post-verification rename ([ADR-032](../adr/ADR-032-oss-context-overlay-and-public-readiness.md), [F23](../features/F23-oss-public-readiness-and-context-overlay.md)).

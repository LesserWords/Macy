# M1 — Research engine and settings (weeks 3–4)

**Goal:** a signed-in owner configures everything in the bilingual UI, and a run collects dated, deduplicated evidence.

**Exit gate:**
- Offline E2E J0–J3 is green.
- A 14-day run stores records for pt-BR and en-US, and a manual check of 20 records finds correct dates and merged duplicates.
- All 18 seed sources are verified.
- The RSSHub and GDELT trials are decided.
